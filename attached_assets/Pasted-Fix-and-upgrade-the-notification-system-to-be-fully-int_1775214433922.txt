Fix and upgrade the notification system to be fully interactive, state-driven, and user-friendly.

---

Current Issues:
- Clicking a notification does nothing
- No read/unread state handling
- Red dot indicator is static
- Notification count on top icon is not dynamic

---

Goal:
- Make notifications clickable
- Open full details
- Mark as read automatically
- Maintain unread count system

---

1. Add Notification Data Structure

Each notification must have:

{
  id: unique_id,
  title: string,
  description: string,
  time: string,
  type: "alert" | "info" | "success",
  isRead: false
}

---

2. Handle Click Event (VERY IMPORTANT)

On clicking a notification:

- Open full notification view

Two options:
(A) Modal popup (recommended)
(B) Navigate to detail page

Modal should show:
- Title
- Full description
- Timestamp
- Optional icon

---

3. Mark as Read Logic

When user clicks a notification:

- Set isRead = true
- Remove red dot indicator
- Update UI instantly

---

4. Red Dot Indicator Logic

- Show red dot ONLY if isRead === false
- If read → hide dot

---

5. Notification Count (Top Bell Icon)

- Count = number of notifications where isRead === false

Update dynamically:
- On click → decrease count
- On "Mark all as read" → count = 0

---

6. "Mark All as Read" Button

When clicked:
- Set all notifications isRead = true
- Remove all red dots
- Reset count to 0

---

7. Persist State (VERY IMPORTANT)

Use localStorage:

- Save notifications array
- Load on page refresh

So that:
- Read/unread state does NOT reset

---

8. UI Behavior Improvements

- Smooth hover effect
- Click animation (slight scale or glow)
- Active notification highlight

---

9. Prevent UI Bugs

- Clicking should NOT close dropdown immediately
- Only close when clicking outside OR after opening modal

---

10. Clean Code Rule

- Single source of truth = notifications state
- No duplicate logic
- No hardcoded counts

---

Final Goal:

✔ Click → Opens notification  
✔ Read → Removes red dot  
✔ Unread count → auto update  
✔ State persists after refresh  
✔ Premium SaaS-like behavior
